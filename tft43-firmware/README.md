# TFT43 Grbl screen firmware

Firmware for the **BigTreeTech TFT43 V3.0** (STM32F207VCT6, 480x272 SSD1963 display,
XPT2046 touch). It replaces BTT's Marlin firmware and talks **Grbl** to the MKS DLC32
over serial:

Screens (tabs along the bottom edge; the stock MKS TS24/TS35 menus plus two new ones):

| Tab | What it does | Stock MKS menu |
|---|---|---|
| DRO | live X/Y/Z work position (large) and machine position, feed, spindle, coolant, pins; zero each axis; Unlock / Home when in alarm; during a job: file, progress, pause / resume, stop (asks first; feed hold, then reset once at rest), feed override | Ready, Carving |
| Jog | jog X/Y/Z in 0.1 / 1 / 10 / 50 mm steps at 300 / 1000 / 2500 mm/min, jog cancel, home all axes (`$H`) or one axis (`$HX` / `$HY` / `$HZ`), zero XY / Z, go to XY zero, probe Z (asks first), unlock | Move |
| Files | list the DLC32's SD card (`$SD/List`), run a file (asks first) | Carve / file |
| Tool | spindle off / 25 / 50 / 75 / 100 % of `$30`, flood coolant on / off, spindle override | Power / Tool |
| Code | G-code console: what was sent and received, the job's current line (needs the `mks_dlc32_v2_1_tft43` DLC32 build), on-screen keyboard to send any command | new |
| Setup | touch calibration, key sound, reset controller, WiFi (show IP, join a network), about | Settings / WiFi |

Not carried over from the stock UI: the "frame" (trace the job outline) and language selection.
The look is shaded rather than flat: gradient buttons with a highlight rim and drop
shadow, recessed panels, and line icons generated by `tools/gen_icons.py`.

Status: **not yet tested on hardware.** The UI and protocol handling are checked in a PC
simulator (below).

## Hardware

| | |
|---|---|
| MCU | STM32F207VCT6, 8 MHz crystal, 120 MHz |
| Display | 480x272, SSD1963 on FSMC (RS = A23) |
| Touch | XPT2046, bit-banged SPI: CS PE6, SCK PE5, MISO PE4, MOSI PE3, PEN PC13 |
| Serial to the DLC32 | USART2 on the TFT's 5-pin "RS232" header: TX PA2, RX PA3, 3.3 V logic |
| Backlight / buzzer | PD12 / PD13 |

Pins and display timing come from BTT's TouchScreenFirmware (`pin_TFT43_V3_0.h`).

Only the **STM32** board is supported for now. Some TFT43 V3.0 boards carry a GD32F205
chip instead (look at the big chip: "STM32F207" or "GD32F205"); those need a different
build.

## Wiring to the MKS DLC32

The TFT43 replaces the TS24 and uses the DLC32's **EXP1** connector. The DLC32 needs the
`mks_dlc32_v2_1_tft43` firmware build, which turns two of the TS24's pins into a serial
port and switches the TS24 screen code off.

| DLC32 EXP1 | Signal | TFT43 "RS232" header (RST, TX2, RX2, −, + left to right) |
|---|---|---|
| pin 10 | 5V | + |
| pin 9 | GND | − |
| pin 7 (IO25) | DLC32 TX | RX2 |
| pin 5 (IO26) | DLC32 RX | TX2 |

Both sides are 3.3 V logic, so no level shifter. EXP1 pin map (V2.1_003): odd row 1 BEEPER,
3 IO5, 5 IO26, 7 IO25, 9 GND; even row 2 NC, 4 IO27, 6 NC, 8 IO33, 10 5V. Check pins 9 and 10
with a multimeter before connecting.

## Flashing

1. Download `BIGTREE_TFT43_V3.0.grbl-<version>.bin` (from the GitHub Actions run, or build it).
2. Copy it to the root of a FAT32 microSD card. The name must start with
   `BIGTREE_TFT43_V3.0` and end in `.bin`, which is what the BTT bootloader looks for.
3. Put the card in the TFT43 and power it on. The bootloader flashes the file and renames
   it to `.CUR`.
4. On first start, or if you hold the screen while the splash is shown, it asks for a
   touch calibration (tap three crosses, then one to check).

**Going back to stock:** copy BTT's `BIGTREE_TFT43_V3.0.28.x.bin` (plus its `TFT43`
folder of fonts and icons) to the card and power on. The bootloader is never touched,
so this always works.

The stock firmware keeps its fonts and icons in the TFT's SPI flash; this firmware has
its own fonts built in and leaves that flash alone. It stores the touch calibration in
the same place and format as the stock firmware, so a recalibration here also resets
the stock firmware's other settings to defaults.

## Building

```sh
sudo apt install gcc-arm-none-eabi libnewlib-arm-none-eabi
make            # build/BIGTREE_TFT43_V3.0.grbl-<version>.bin
make sim        # PC simulator: protocol checks + screenshots in sim/out/
```

`src/fonts.c` is generated by `tools/gen_fonts.py` from DejaVu Sans Mono Bold, and
`src/icons.c` / `src/icons.h` by `tools/gen_icons.py`.

## Layout

```
src/main.c          start-up, calibration, main loop
src/grbl.c          Grbl protocol: status parsing, command queue (one line in flight), SD list
src/ui.c            screens and touch handling
src/gfx.c, fonts.c  drawing, anti-aliased fonts
src/*_stm32.c, hw.c hardware: SSD1963/FSMC, XPT2046, USART2, clock, GPIO
sim/                PC versions of the hardware layer + a scripted test
vendor/             CMSIS + ST standard peripheral library (from BTT's tree and ARM CMSIS 5.4.0)
ld/                 linker script, app at 0x08008000 after the BTT bootloader
```
